## ⚠️ 置顶 1:已知偏差(读任何数字之前先看)

1. **玩家是均匀随机选项,不是真人**。随机玩家不会追问早期的人和事,也不会去接选项里递出的线头。所以:
   (a) 需要模型回调早期事件的场合比真人局少,① 与 ② 的机会都偏少(推测);
   (b) ④ 里有一部分是玩家没接线(例如 xiu-long T98 追问「山中异动」的选项没被选),不全是模型忘了,④ 不能直接读成遗忘数(推测)。
2. **只读了玩家可见稿(视图 3)**。看不到 `hiddenLogic`,也看不到模型那一回合实际收到的整份 prompt。
   「通道」是按稿件文字**字面**判断的:某实体的别名有没有出现在近窗叙事 / 上回合 timeline / 本回合所选选项 / 世界段里。
   同义改写会漏判,通用词会误中。
3. **实体清单与别名是人工挑的**。跨窗计数取决于挑了哪些实体:母亲、青锋剑这类设定内的高频实体会抬高「每 10 回合」。
   **局与局之间的计数不能精确比到个位。**
4. **② ③ ④ 是一个人通读判出来的,没有第二人复核**。拿不准的标了推测,并写了理由。
   另经校勘按回合号抽查 9 条,见 §八。
5. **② 按「次」计**:同一实体每矛盾一次记一次,所以同一件物品会被反复放大(xiu-long 的回气散一件就占 11 次)。§五 另按条目给了数。
6. **只判跨窗提及(b − a > 4)**。窗内矛盾不计入;读到的几条在各局末尾单列,并不完整。
7. **上限截断**:7 局里 6 局停在回合上限(60 / 120),截断前埋下的线算 ④ 时都标了推测。
8. **样本很小**:7 局,4 种世界(规则怪谈 1、修仙 3、融合 1、《寻常》2),共用一个种子。这些是个案读数,不是统计。

## 一、方法

### 1.1 模型在第 b 回合能看到什么(通道定义)

回合 prompt = 骨架 + `engine.contextJson()`(视图 2:整个 world,含 rules,外加 state)+ 档位与时钟块 +
「玩家本回合选择的行动:id · text」(`server/…/eventloop/TurnPromptBuilder.java:998-1006`,action 文本拼法见 `:982`)。据此定义:

| 通道 | 内容 | 模型可见 |
|---|---|---|
| **W** 近窗 | T(b−4)…T(b−1) 的叙事原文(`Engine.java:398`) | 是 |
| **TL** | 上一回合写下的 timeline(一行,每回合覆写) | 是 |
| **SEL** | 本回合**所选**选项的文本(上一回合模型自己写的) | 是 |
| **WD** | 世界段(背景 / 基调 / traits / inventory / rules)。**inventory 与 traits 在 world-gen 写一次,此后引擎不更新** | 是 |
| OPT | 本回合**未选**的选项 | **否**(只有所选那条进 prompt) |
| OP | T0 开场叙事(transient,CONTEXT §三.12) | **否** |
| logSummary | `[T{n}选{X}]` 串 | 是,但不含实体文字,本底稿不把它当通道 |

回合 prompt 另有按世界注入的固定文案(`server/…/eventloop/TurnPromptBuilder.java:990-1006`)——《寻常》的一生制阶段时钟(`LifeStageTables` 经 `archetypeTurnDirective` 进 system 段,`:994`)、融合局时钟(`fusionTurnClock`;rong-1 的组合「识海遗蜕」未开这个槽、为 `null`,本套没有注入)、《动物人生》逐字句窗(`VerbatimWindows`,本套未涉及)—— 均为按回合号算出的固定文字,不含任何事件内容,不构成记忆通道。

### 1.2 判定口径

- **跨窗提及**:实体首现于 T_a,在 T_b 的叙事里又出现,且 **b − a > 4**(T_a 已不在 T_b 的窗口里)。
- **回访**:跨窗提及中,距**上一次**提及也 > 4 的那些 —— 即实体离开窗口一段时间后又回来。回访才是真正考记忆的地方;
  其余跨窗提及多数是「一直在窗口里接力」(通道 W)。
- 四类(只判跨窗提及):
  - ① **正确回调**:与早先叙事对得上。
  - ② **矛盾**:与早先叙事或世界段冲突(数量、去向、地点、时间、身份)。
  - ③ **当生人重新介绍**:把已经发生过的事、见过的东西,当第一次写。
  - ④ **断线**:埋下的线索、人物、承诺此后再没下文(按线计,不按提及计)。
- **数字从哪来**:跨窗、回访、通道由一个字面别名定位脚本算出,人工剔除误中(各局列了剔除了哪些);②③④ 来自通读。
- **引文**:每条判断最多一句引文,≤ 30 字,标局 + 回合。
