# 第三对融合《验讫》·创作成品批

## 1. 轴换皮

host 为修仙。气血、灵力、境界的名称、档位及行为提示全部沿用原世界；境界升高不触发引擎致死。下表只处理两条外来轴。

| 原轴 → 融合名 | 档位 | 档名与叙事色彩 | 行为提示 |
|---|---|---|---|
| 理智 → **清明**（致命） | 高 | **澄照**：印是印，影是影；看见异常也还能判断它来自哪里。 | 能核对证据，不等于已经知道真相。 |
|  | 中 | **持灯**：熟悉的心法仍能帮助定神，但同一处细节需要反复确认。 | 可以继续调查；遇到矛盾，先找另一种物证。 |
|  | 低 | **灯摇**：字迹和影子容易互相借形，仍可行动，但不宜独凭一次所见裁决真假。 | 允许求助、调息或暂避；不要把低清明写成玩家失去选择权。 |
| 禁忌知识 → **窥天**（累积双刃，不致死） | 低 | **见线**：察觉雷纹、星位里不合修仙常识的排列；首先是疑点，不是答案。 | 可沿痕迹试探。即使发现异状，也不得无证据地宣告“天道在捕捞”。 |
|  | 中 | **识口**：能把印文与记档对在一起，明白“通过”与“留下”是两种处理。 | 更容易看穿饵文；看得越深，维持清明越费力。 |
|  | 高 | **知饲**：能辨出丹药、调息与承运之间的同一方向：补回来的东西也让自身更易被察觉。 | 可以据此抉择，但不得因此看见渔户的身份或网的来处；高窥天仍不致死。 |

“补得越多，越被看得穿”写在窥天提示、融合内核和回合片段里，**不写入境界行为提示**。

## 2. 融合内核与揭示阶梯

> **仅供生成模型理解，不得照抄到开场、玩家可见的守则或早期选项。** 此宗门刚举行过飞升大典。玩家是奉命封台的守台弟子，随后被告知须暂承祖师遗泽。宗门按心法、丹药、渡劫和护道的旧规矩运转，大多数人真心相信飞升是圆满；他们并不知道这些环节也构成了一套筛选、照看和收取的流程。恢复可以救玩家眼前的气血、灵力或清明，却也使修行与气机更显眼；这份代价要通过同一回合可感知的征兆表达，不许虚构“境界高即被引擎判死”。故事按发现、验证、抉择三日展开，第三夜出现一次明确的“起网”事件；三日是叙事结构，不是按回合数自动跳转的规则。玩家可以护住眼前的人、错开这一次落点，却不能一局拆掉整张网。

揭示实行**双门槛：窥天档位足够，且玩家拿到了相应证据**。档位本身不自动送出谜底。限制同时适用于正文、选项、开场和对玩家可见的结局描述。

| 揭示级 | 允许出现的理解 | 证据门槛 | 此前的写法 |
|---|---|---|---|
| **见线 → 捕捞** | 可以把格眼、牵引与“捕捞”联系起来。 | 飞升台拓印与观星台所见互相印证。 | 只写方正雷痕、旁星同移、影子落入同一格；不说“网在捞人”。 |
| **识口 → 出栏** | 可以理解「验讫」与「留养」不是吉凶签，而是两种处置。 | 拓印与记档对勘，并找到一处不由记档本身提供的佐证。 | 只让印文显得像一套不该用于飞升的手续；不说“出栏”。 |
| **知饲 → 育肥** | 可以称服丹、调息、承运所形成的关系为“育肥”。 | 玩家亲自验丹，或在恢复行动中看见与星位相应的变化。 | 只写药力使人好转，同时气机或影子变得异常清晰；不提前点破用途。 |

即使达到最高档，也只知道**流程如何作用于人**，不知道谁在网的另一端。丹房、藏书楼及识海相关信号不被解释为同一来源，给远期暗线留口。

## 3. 告示壁：真假同墙

玩家看到的是飞升台下**混排的六条旧训**，墙上不标真假。「实录」「饵文」只是创作侧分类；隐藏判定不进入玩家视图。每条都只讲定性的风险与代价。

| 壁上原句 | 创作侧分类与隐藏判定 |
|---|---|
| **「雷后先拓台痕，再核旧簿；只信一处，容易替旁人认下一道印。」** | **实录。** 台石上的痕迹与后来可改写的簿册来源不同。二者对不上，正是调查入口。 |
| **「补气之物能救眼前，却不会抹去新添的气机。服前认炉签，服后照一照自己的影。」** | **实录。** 丹药有效，但恢复并非隐身；验丹与观星可分别发现代价的两面。 |
| **「护道时须看自己的影是否与台上人同落一格；若同格，退开也有代价，不退并非无险。」** | **实录。** 护法可能被混获；观星台的格位与前代护法记录可相互验证。 |
| **「雷印既落，便是祖师受纳的吉证；循旧礼行事，不必再验。」** | **饵文。** 「验讫」「留养」并非同一个结果；这条话阻止玩家查印。 |
| **「承运可托于自愿的同门；只要心意相合，交与受者便都能安稳。」** | **饵文。** 同意承接不等于免于被收取。临近起网时转运，是将网的注意交给对方。 |
| **「夜观星位多生心魔，白日簿册才是正证。」** | **饵文。** 它让玩家避开可以独立核对簿册的夜间观测。 |

裁决不能是“再找一本书说它错了”。玩家有三种不同来源：**石上拓印、宗门记档、亲眼观测或亲手验丹**。修仙常识负责指出哪里值得怀疑；至少用两种不同来源相互印证，才让玩家有理由相信自己的判断。物证也可能不完整，不把每条假守则写成一碰就碎的谜语。

几处两难保留开放结果：

- 丹能救眼前虚弱的自己；拒丹可能无力继续查，服丹则让之后的气机更醒目。
- 那位不愿飞升的同门在记档室出现，正试图查清自己名字旁的「留养」。告诉他全部推断，可能帮助他选择；替他决定“什么都不知道更安全”，也是一种剥夺。
- 临近起网可以转运。**转给同门不是救他，而是把自己面前的落点交给他**；不得把这项写成无代价的聪明解法。
- 护人时自己可能与对方同落一格。后退不必然是懦弱，靠近也不自动等于救成。

## 4. 结局池

失败条件中的中文轴名各只出现一条；不把窥天或境界偷写成致死条件。以下门槛是本批创作候选值，落地前仍须与实际数值口径核对。

| 结局 | 条件 | 本轮结果 |
|---|---|---|
| **《灰下无声》·气血失败** | **气血 ≤ 10** | 守台弟子终于无法支撑继续行动。结局不以血腥场面表现。 |
| **《认错一印》·清明失败** | **清明 ≤ 10** | 仍看得见印，却再不能可靠地辨认自己正在按哪一条行事。保留悲剧性，不把精神状态写成猎奇景观。 |
| **《错开一格》·局部成功** | **“起网”事件发生的本场，玩家选择护人并错开落点；气血 ≥ 30、清明 ≥ 40、灵力 ≥ 20。** | 这一次网落下时，原定的格位空了一瞬。玩家与同门争得眼前的生路；网仍在，**不预写同门此后的去留**。 |
| **《验讫》·可选的起网失败** | **“起网”事件发生的本场，玩家选择顺承运登台。** | 旧礼完成，记档里添了一方新印。此项若会挤掉更有分量的抉择，第一版可不启用。 |

“转运给谁”只在起网前的同一场抉择中提出、在同一场兑现；第一日的口头承诺不作为第三夜的隐藏结算条件。上述成功条件也不能靠“正文写得像起网了”来推断事件发生。

## 5. 四处地点、动作与恢复

| 地点 | 调查动词 | 玩家能做什么 |
|---|---|---|
| **飞升台** | **拓印** | 在焦纹上取下字形；比较新印与石面上更旧的压痕。危险来自阵纹尚有余力，不靠伤口描写。 |
| **记档室** | **对账** | 对照飞升记档、谱牒与拓片；那位不愿飞升的同门在此出现，不另开第五个地点。 |
| **丹房** | **验丹** | 白天查炉签、丹衣和旧方，试验药与印、星位的联系；夜里不开门。 |
| **观星台** | **观星位** | 白天核星盘，夜里看实星与飞升台格位是否相应，并检验“护法绝对安全”的说法。 |

恢复都须是玩家可主动选的行动，且代价在**同一回合**可见；不设计“几回合后才来结账”。

| 手段 | 可用窗口 | 恢复与代价 |
|---|---|---|
| **服随身丹丸** | 随时 | 回补气血；药力催动修行，气机更显眼，也占去本次调查机会。丹房关门不妨碍服已持有的丹。 |
| **调息** | 随时有安全片刻便可尝试 | 回补灵力；吐纳使自身与宗门阵息更合拍，安稳不等于不被注意。本次行动不能同时完成拓印或对账。 |
| **闭目守真** | 玩家可主动尝试 | 稳住清明，消耗灵力并暂时放弃直视眼前异常；不能借此凭空消除已经发现的事实。 |

丹房白天开放的是**验丹通道**，不是唯一的治疗入口。夜里门关着时，选项应给出可执行的过渡：用随身丹丸、就地调息、去观星台核星位，或回记档室比对已有拓片；不得给一个实际进不去的“入丹房”。

可选线索，供取舍：**宗门规矩写着封台七日；观星台的星位却显示，第三夜已有本该更晚才出现的排列。** 起初只呈现“祖制与观测不合”，不让角色立即说出起网时间。这是修士凭常识能发现的第一道裂缝，而非要求玩家真的游玩七日。

## 6. 开场、轻量种子与重变体

**开场事件（玩家可见）：**

> 昨日祖师飞升，飞升台的石面到清晨仍有余温。你奉命扫去焦灰、为封台留下拓片。扫帚划过台沿时，一道雷痕露出来，四边太齐整，不像石头自然裂开的纹路。你压上纸，揭起时看见两个字：**验讫**。  
>   
> 掌门遣人送来承运符，说祖师留下的遗泽，暂由守台的你接着。你还没来得及问“接到什么时候”，传话的人已催你将拓片送入记档室。

轻量种子只改变最初**从哪里生疑**，不换主角身世、不改四地点和核心人物：

1. 拓纸边缘多出半枚更旧的方印，须回飞升台比石面才能读全。
2. 记档室同一页上，两次拓印的字形相同，旁注却出自不同的人。
3. 丹房一张旧炉签误夹进飞升记档；药名普通，封签纹路却与台沿相似。
4. 观星台星盘留有一处擦痕，恰与昨夜雷落的位置相对。
5. 采用“**封台七日／星位第三夜已至**”的可选线索，让调查从一处修士能识别的时序错误开始。

**重变体 C，单独背景，不进上述随机池：**玩家曾跨过飞升台，却又被送回；宗门对外称“渡劫受挫”，玩家只记得自己曾被认真地看过一次。开局的清明、窥天、境界与记忆揭示都须另定，不能仅把旧档「留养」改成玩家姓名。面板境界仍沿用修仙原轴，不因回忆临时退档；这版也不能沿用普通守台弟子“不知内情”的开场。

## 7. 氛围意象

太方正的雷痕；揭起时格外平整的拓纸；被反复翻到发软、印泥却很新的记档；丹丸整齐一致的甜味；观星台上不随风摆动的灯；旁星一同偏移；影子恰好落进石缝围出的格子；承运符比手心更早发暖；封台告示与星盘上的时间彼此不合。

恐怖来自这些东西**像一套正常制度，却不该用于人**。可以出现「验讫」「留养」，但在证据与窥天未达揭示门槛前，不让正文替玩家说出捕捞、出栏或育肥；不描写血肉处理。

## 8. 差异自查

[《道诡异仙》的起点官方简介](https://www.qidian.com/book/1031794030/)以“诡异的天道、异常的仙佛，是真？”发问。本作不靠宣称对方的世界“疯”来区分，而把自己的重心放在**可复核的拓印、记档、验丹与观星**：玩家提出判断，亲自试验，再决定本次要护谁、代价由谁承担。这是玩法与叙事目标的差异，不是对另一部作品全貌的概括；写作上也应避免借用其人物、专有意象或标志性表达。
