# 《派单》Slice G-2 静态样张

ADR-036「Slice G-2(草案)」的配套样张。**只供裁定,不是实现**:`web/src` 零改动。

## 怎么做出来的

- dev server(`web` + `server`)上续一局本地《派单》存档(第 7 回合;续局只走 `GET /api/game/{id}/state`,不调模型、不花 key)。
- 在浏览器里把 [`sample.css`](sample.css) 注入页面:选择器按 CSS Modules 的类名前缀匹配(如 `[class*="_prose_"]`),
  只改颜色、边框、圆角,DOM 不动。
- 记忆点那一帧另外往顶图里插了一个 `.paidanHud` 元素(样张专用)。
- 卡面那一帧把赛博朋克卡挪到规则怪谈与克苏鲁之间(末日挪到克苏鲁之后),只为截图比较相邻的深色卡;真实顺序不变。
- 截完已删掉注入的样式和种进浏览器的存档指针;服务端存档文件未被改动。
