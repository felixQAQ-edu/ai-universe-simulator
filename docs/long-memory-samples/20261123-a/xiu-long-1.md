## 世界(视图 3)

- 背景:青云宗坐落于东岭云海之间,后山灵药园是外门弟子轮值看护的差事。你入门未久,炼气初成,被执事分派独自守园七日七夜。园中灵草受月华滋养,亦引来山中妖兽与不轨之徒觊觎。宗门规矩森严,守园失职者轻则废去修为逐出山门,重则性命难保。
- 基调:你刚入青云宗,炼气未稳,就被独自派去守一片夜里会发光的灵药园——七日之内,园在人在,园毁人亡,而山风里似乎有东西在盯着你。
- 人物:traits 双灵根、炼气初期、外门弟子、心性未定 · inventory 宗门制式青锋剑、守园令牌、半瓶回气散
- 规则:
  - #1 心魔不可纵,纵则走火入魔——修行时若贪快求进,心念稍偏,便为心魔所乘。
  - #2 灵力枯竭而强运功法者,经脉俱损——法力耗尽时强行施术,反噬自身。
  - #3 守园之责,园在人在——灵药园若遭损毁,宗门必究,轻则废修逐出,重则性命难保。
  - #4 妖兽畏光惧火,夜间灵药园灯火不可断——灯火一灭,阴物便至。
  - #5 丹药不可轻服,服之过量则药力反噬,经脉胀痛。
  - #6 渡劫忌分心,心念一乱,天雷便至——虽炼气未至渡劫,然修行处处是劫。
  - #7 同道相争,留一线生机——斩尽杀绝者,道心易偏,日后必遭反噬。
