## 世界(视图 3)

- 背景:1978年，西北农场。你生在这里，排行老三。父亲走的那年你还记不清他的脸，只记得母亲把他的棉袄改小了给你，袖口磨得发亮。家里的粮本压在柜子最底下，比钱要紧——钱买不到定量，粮本上的数字才决定这个月锅里能有多少。母亲一个人拉扯三个，天不亮就去地里，回来时手上裂着口子。你跟着同乡一起去放羊，草滩上风大，羊走得慢，你们也走得慢，一整天说不了几句话，可那些话你后来记了很多年。
- 基调:你生在西北农场的土坯房里，排行老三，粮本压在柜子最底下，母亲的手一年到头都是裂的。
- 人物:traits 寡言、耐劳、记性好 · inventory 母亲改小的旧棉袄、半块干馍、放羊用的短鞭
- 规则:
  - #1 粮本上的数字是死的，人是活的——可活人也得按死数字过日子。你后来才明白，家里最先紧的从来不是嘴，是母亲说话的声音。
  - #2 有些话在草滩上说过了，就再也没法当作没说过。可说完之后，那人还是照常赶羊，你也照常赶羊，日子不会因为一句话拐弯。
  - #3 身体是有账的。年轻时欠下的觉、扛过的冻、忍过的饿，都记着，只是不当场要。等到要的时候，你多半已经想不起来是哪一年欠的了。
  - #4 人这一辈子，能自己做主的事比想起来的少。有些门是在你没留意的时候关上的——不是谁关的，就是日子过着过着，那条路就走不成了。
  - #5 母亲从没说过苦。你后来才知道，不说不是不苦，是说了也没用，还得留着力气第二天早起。
  - #6 有些东西一直没扔。不是舍不得，是每次收拾的时候手伸过去，又缩回来了。等哪天真扔了，反倒想不起当初为什么留着。
  - #7 谁家有事，队上的人都来。来的人不一定帮得上忙，可来了，那家就还在这片地上站着。

## T0 开场

天还没亮透，母亲已经在灶前忙了。锅里是稀得能照见人影的糊糊，她给三个碗分得匀，自己那碗最薄。你蹲在门槛上喝，风从门缝里钻进来，吹得后颈凉。

粮本压在柜子最底下，母亲昨晚又翻出来看过一遍，看完没说话，塞回去的时候手在柜门上停了一下。

同乡在院墙外喊你，声音被风扯得断断续续。羊圈那边已经开了栏，羊叫得急。你站起来，棉袄的袖口磨得发亮，是父亲留下的那件改的，母亲的手艺，针脚密。

母亲没抬头，只说了一句：路上看着点。

你不知道她说的是羊，还是别的什么。
