## 世界(视图 3)

- 背景:太虚山下,云海翻涌,太虚宗屹立千年。宗门大比前夜,弟子们或闭关调息,或演练法术,唯有外门杂役处的柴房还亮着昏灯。你,一个被同门讥为“废灵根”的弟子,正借着月光修补明日要用的法器。忽然,柴堆缝隙里滑出一卷焦黄残破的帛书,上面以古篆写就《九转混沌诀》——传闻中早已失传的逆天心法。残卷只有三页,字迹模糊,却隐隐有灵光流转。你心跳如鼓,窗外巡夜的师兄脚步声渐近。
- 基调:大比前夜,你攥着一卷残破心法,柴房外是同门的冷笑与巡夜的脚步——修不修?怎么修?修了,或许能翻身;不修,明日照旧被人踩在脚下。
- 人物:traits 废灵根、外门杂役、心细如发、隐忍 · inventory 半块下品灵石、旧铜镜、残破心法帛书
- 规则:
  - #1 心魔不可纵,纵则走火入魔。修行途中,凡有杂念执妄,当以静心诀斩之;一念放纵,轻则灵力逆冲,重则神识昏乱。
  - #2 灵力枯竭时强行运功,经脉俱断。灵力耗尽当止,不可强催;否则经脉受损,修行倒退。
  - #3 渡劫忌分心,心乱则劫雷噬身。天劫降临时,当凝神守一,不可有杂念、不可有外物干扰,否则劫雷威力倍增。
  - #4 残卷功法不可贪多,贪多则灵气驳杂,根基不稳。修行当循序渐进,一日不可贪修多页。
  - #5 同门相争,不可轻信。宗门之内,利益纠葛,凡他人赠丹赠物,当察其来路;轻信则可能身陷圈套。
  - #6 天材地宝,有德者居之,强取则遭反噬。灵物有灵,若以蛮力夺取或不顾自身修为强行炼化,轻则灵力紊乱,重则灵物自毁伤人。
  - #7 夜半子时,阴气最盛,不宜在外门荒僻处吐纳。此时修炼,易引阴煞入体,扰乱灵力。

## T0 开场

柴房漏风,月光从破窗的缝隙里漏进来,照在你膝头那卷焦黄的帛书上。帛书只有三页,边缘烧灼的痕迹像是被人刻意毁去,可残留的字迹仍泛着幽幽灵光——“九转混沌诀”,你曾在宗门典籍阁的残页里见过这个名字,据说是上古魔道心法,早已失传。你听见自己的心跳声,比窗外巡夜师兄的脚步声还响。外门杂役的粗布衣上还沾着柴屑,明日大比,你连一件像样的法器都拿不出。同门们此刻正在丹房领丹药、在演武场借月光练剑,而你蹲在柴堆里,手里攥着一卷可能让你翻身、也可能让你万劫不复的东西。风从门缝钻进来,帛书的一角轻轻翻动,像在催你做个决定。
