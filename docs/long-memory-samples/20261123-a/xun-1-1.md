## 世界(视图 3)

- 背景:1985 年，北方一座钢铁厂的家属区。楼是红砖的，一层四户，走廊里堆着蜂窝煤和酸菜缸。你父亲在轧钢车间上三班倒，回家时身上总有一股铁锈和机油混在一起的味道，倒头就睡，醒来就着咸菜喝两口。你母亲在厂财务科当会计，算盘打得比谁都快，家里的钱由她锁在五斗柜最上层，存折上的数字她记得比自己的生日清楚。你是独子，住三单元二楼西户。隔壁楼有个和你同岁的女孩，叫小满，她家门前的晾衣绳上常年挂着她妈的蓝布工作服。厂区大喇叭每天早中晚各响一次，广播员念完通知会放一段歌。冬天管道冻，夏天电扇转，日子按班次和学期往前推。
- 基调:你生在1985年的家属楼里，父母都在厂里，家里不富也不缺，接下来几十年，你要慢慢弄明白一件事：日子不是选出来的，是过出来的。
- 人物:traits 独生子、听话、记性好、有点怯 · inventory 一张家属楼出入证、母亲给的五分钱、一辆小三轮车
- 规则:
  - #1 父亲下夜班回来那天，家里说话要轻。他在车间站了八个小时，耳朵里还响着轧机的声，你吵一句，他能记一整天。
  - #2 母亲算账的时候，别站在她身后看。她不是怕你看，是那本账上有她不想让人看见的地方——给姥姥家寄的钱，给你攒的学费，还有一笔她一直没动。
  - #3 小满家搬走那年，你才发现隔壁楼和你们楼之间那道墙有多薄。后来再有人搬进来，墙还是那么薄，可你不再听了。
  - #4 厂里发东西的时候，谁家多一袋谁家少一袋，母亲从不争。她说争来的东西，下回还得争。
  - #5 你父亲这辈子只打过你一次。那次之后，他再没动过手，也再没提过那件事。你后来想起来，觉得他可能比你还怕。
  - #6 存折上的数字会变，但变的方式和你以为的不一样。你以为它慢慢涨，其实它是在某几个年份突然少一截，然后很久不动。
  - #7 厂区大喇叭后来不响了。没人通知你它哪天停的，你就是有一天发现，早上出门的时候，院子里安静得不像话。

## T0 开场

1985年秋天，你六岁。早上六点半，厂区大喇叭响了，先是一段《东方红》，然后是广播员念通知：三车间今天检修，轧钢车间正常上班。你母亲在厨房煎鸡蛋，油星子溅到灶台上，她拿抹布一擦，顺手把你的小碗推到桌子中间。父亲夜班刚回来，鞋没脱就歪在里屋床上，呼噜声从门缝里漏出来。你坐在小板凳上，脚够不着地，手里攥着母亲给的五分钱，打算一会儿去小卖部看看有没有新到的糖。窗外，隔壁楼的阳台上有人在抖床单，白色的布在灰扑扑的楼面上鼓起来又落下。你听见楼下有小孩在喊人，声音很细，像是小满。母亲说，快吃，吃完别在楼道里跑。你咬了一口鸡蛋，蛋黄是溏心的，烫了嘴。这一天和别的日子没什么两样，你也不知道它会通向哪儿。
