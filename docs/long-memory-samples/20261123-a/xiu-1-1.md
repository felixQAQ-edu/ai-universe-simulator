- 基调:你盘坐枯云洞深处,丹田灵气正撞着筑基的关隘,而洞外的脚步声,已经比劫云更近了。

- 规则:
  - #1 心魔不可纵,纵则走火入魔。破境时心念一起,杂念便如藤缠道基,愈挣愈紧。
  - #2 灵力枯竭而强行运功者,经脉如枯河断流,轻则术法反噬,重则道基留裂。
  - #3 渡劫忌分心。天雷落下时若旁骛他顾,劫力便会循隙而入,加倍噬身。
  - #4 丹药可续命,不可当饭。同一时辰连服数丹,药力相冲,反成毒火。
  - #5 境界高者镇压低者,如大石压卵。以低境硬撼高境,凭的是命,不是理。
  - #6 灵气外泄如灯火照夜,破境之际最易引来同道的觊觎与仇家的刀锋。
  - #7 伤重而强撑者,气血暗耗于无形。看似无恙,实则命火已薄。
  - #8 洞天福地有主,擅入他人道场,阵眼一开,便是有进无出。
