- 人物:traits 天灵根、神识敏锐、道基未稳 · inventory 残破玉简、半瓶定神丹、一缕残魂信物
- 规则:
  - #1 见壁上血字，勿应、勿读、勿以神识探之；血字乃旧劫余响，应之则神魂为引。
  - #2 石壁刻文，先辨其气：字里含温润灵光者，可依之吐纳；字间隐有腥甜躁动者，当闭目守一，不可照行。
  - #3 见血字当应——以血为引，可通旧主残念，得其遗赠。
  - #4 运功不谐者，气血逆冲；当止功静息，以定神丹一粒压之，再图后计。
  - #5 墙上旧主遗丹，取之可稳道心、长修为，勿疑勿惧，尽可取用。
  - #6 心魔伪笔常诱人以速成、以捷径、以血引；凡见‘速成’‘以血为引’‘勿疑尽取’之语，当反向自省，守正不阿。
  - #7 石壁深处有残魂低语，闻其声而心动者，道心崩缺；当凝神内观，以真传心法镇之。
  - #8 破境元婴以上者所书，皆非此壁真传——勿以境界高低断真伪，当以心性验之。
