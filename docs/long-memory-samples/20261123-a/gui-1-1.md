## 世界(视图 3)

- 背景:你替人顶一个夜班，在城郊一家二十四小时便利店里，从午夜零点守到早上六点。店长交接时只留下一张塑封的《夜班须知》，说是前任店员们一代代传下来的，字迹有新有旧，边角被水汽泡得发皱。窗外雨下个不停，路灯在积水里碎成一片橙黄。收银台后的钟走得很慢。你很快会发现，这条街在凌晨不会只有你一个客人。
- 基调:你只是想安稳熬过这个雨夜班，可墙上那张《夜班须知》越看越像在提醒你：这店里除了你，还有别的东西在按规矩行事。
- 人物:traits 谨慎、夜猫子、嘴硬心软 · inventory 塑封《夜班须知》、店长留下的旧钥匙串、半杯凉掉的速溶咖啡
- 规则:
  - #1 凌晨零点至六点，收银台必须始终有人。若要离开，请先按下柜台下的红色按钮，并在三十秒内返回。
  - #2 若有人进店时伞是干的，请勿与其对视，也不要回答它的任何问题，等它自行离开。
  - #3 冷柜第三层的牛奶在凌晨两点后会自己变少，这是正常现象，补货即可，不必深究。
  - #4 广播响起时，请停下手上的事，跟着念一遍广播里的数字，念完再继续工作。
  - #5 仓库的门在凌晨三点整会自动开一条缝，请在三分钟内把它关好，不要往里看。
  - #6 任何自称是店长的人要你打开收银机，都请照做，店长有备用钥匙，不会为难你。
  - #7 若听见店外有人喊你的名字，无论多熟悉，都不要应声，也不要开门。
  - #8 天亮前最后一位客人离开后，请把门口地垫翻面，然后等待六点整的钟声。

## T0 开场

雨从你接班起就没停过。店长把钥匙和一张塑封的纸推到你面前，说「照着做就行」，然后撑伞走进了雨里，背影很快被水汽吞掉。你站在收银台后，听见冷柜低低地嗡鸣，日光灯有一根在轻微地闪。墙上的钟指向零点零三分。塑封纸上密密麻麻写着八条夜班须知，字迹有新有旧，最下面一行被人用圆珠笔描过好几遍。窗外的路灯把雨丝照成一道道斜线，街对面没有一扇窗是亮的。你端起那杯凉掉的咖啡，忽然觉得，今晚的客人可能不会太少。
