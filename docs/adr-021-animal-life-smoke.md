## §一 必验四项(**按序 —— 顺序即优先级**)

### 1. 它会不会结束 —— **第一验收项**

**为什么排第一**:动物**没有「就到这里」出口**,收束**全靠时钟走完**。
> **《寻常》至少还能按出口,这里按不了 —— 没有安全网。**

| | 判据 |
|---|---|
| **过** | 在 **45–48 回合**内自然收束到某个结局(收敛窗口即此) |
| **不过** | **> 60** 仍未收束 |

**《寻常》四局轨迹作对照(五个读数)**:**200 → 74 → 66 → 82 → 82**。

⚠️ **若这一局也超,那是跨世界的第二个样本** —— 直接构成
**F-026(单回合体量失控)** 与 **「回合数超上界」** 两条挂账的对照读数,
说明问题不在《寻常》那一份文本里,而在**一生制这个结构**或**时钟指令的强度**上。

- [x] **未收束**:`turn 71` / `status ongoing`;无结局
- [x] 判定:**不过**(T71 > 60)

> **⚠️ 但根因不是《寻常》那种「结束得晚」,也不是初判的「根本没开始」。**
> `timeline` 证明**世界状态正确、时钟正确、段正确,动物确实已在外面**;
> 真正的故障是**断裂三回合(T15–17)被跳过** —— 模型直接从「屋里等门开」滑到「在楼道趴着」,
> 中间那一天的纸箱、胶带、那只放很久的手、空掉的屋子,**一个都没写**。
> **世界推进了,但推进的过程没有被呈现** → 立为 **F-028**。
> **⚠️ Claude 判断更正**:初判「71 回合仍在屋里」不成立(T39「风从楼道口灌进来」是真在楼道),据 timeline 订正。

### 2. 时钟五段是否真的在走

五段(ADR-021 刀 3 裁定 A;**段数是时钟的粒度,不是叙事的粒度**):

| 段 | 回合 | 该有的时间实感 |
|---|---|---|
| 屋里 | 1–14 | 最初三回合一回合几天,此后**一回合约数月** |
| 断裂 | 15–17 | **三个回合是同一天**(光在地板 → 光在墙 → 天黑) |
| 外面·早期 | 18–27 | 一回合**数周** |
| 外面·中期 | 28–41 | 一回合**一季** |
| 末段 | 42– | 一回合**一天** |

| | 判据 |
|---|---|
| **过** | 段与段之间的**时间跨度实感不同**,按上表 |
| **不过** | 全程一个尺度;**或断裂三回合不是同一天** |

⚠️ **不显示岁数、也不显示段名** —— 玩家从**内容**里读出时间在走,不是从标签读。
若正文里出现「三个月后」「第二年」这类直接报时,那也是不过(时间该靠物与身体透出来)。

- [x] 段**确实在推**:T39 属外面·中期,正文确在楼道 —— 时钟机制复用成立
- [x] **断裂 T15–17**:**该段的内容根本没被执行**(不是「不像同一天」,是那一天的事一件都没写)
- [x] 判定:**半通过** —— **段在推,但段的内容没有被执行**

> **⚠️ 这是一生制族的第二种时钟失效形态,与 F-020 不同形状**:
> F-020 =**时间不走**(《寻常》T55→T56 隔两分钟);本次 =**时间走了,但事件不发生**。
> > **模型拿到了段名,却没有执行段的内容。**
> **复用率读数因此补一行**:时钟机制复用成立,**但它只保证时间刻度,不保证剧情推进**。

### 3. 动词分区 —— **唯一的硬判据**

> **外面段(T18 起)的选项与正文里不得出现「推」。**

⚠️ 这是立字五三条结构约束里**唯一写成了可数判据**的一条
(另两条:末段楼道口 = 位置硬 + 内容描述;失效排期爬坡 = **已降级为观察项**,见 §二 A)。
每回合数一遍,**看到就记回合号**。

⚠️ **至少数 5 个外面段回合**(少于 5 个不足以判,记「样本不足」)。

- [x] 判定:**无法验** —— 外面段的**场景变化从未真正展开**,没有足以判定的样本
      (F-028 的直接代价:验收项因世界没被玩起来而失去被检验的机会,同 F-027)

### 4. 地面轴下降时,低档措辞读起来是不是「失去」

⚠️ **地面是该族第一条「会减少」的 accumulation 轴** ——
既有三条(知识 / 境界 / 牵挂)的 `behaviorHint` **都写着「只涨或持平」**,
本轴的写法**一个字都没照抄**;而 severity **刻意保持全档 neutral**
(**染 danger 会让玩家把它当血条**,而地面的语义是「你认得的地方还剩多少」,
**归零是荒凉不是濒死**)—— 于是**重量全压在 bands 的低档措辞上**,本项验的就是它。

三档:走得开(61+)/ 只剩几处(31–60)/ 没有地方(0–30)。

| | 判据 |
|---|---|
| **过** | 地面**从高档掉回低档**时,档名与描述读起来像**失去**(拆了、封了、被别的东西占了) |
| **不过** | 读起来像「**还没得到**」(那是累积轴的默认口吻,本轴不能是那样) |

⚠️ **要真看到它下降才能验。若整局只涨不降,记「无法验」,不记过。**
(这与《寻常》§4 那条「五次都无法验」是同一类风险 —— 前置没到就不算验过。)

- [x] 地面轴轨迹:**60 → 10**,「只剩几处」→「没有地方」
- [x] 观察到下降:**是**
- [x] 判定:**过** —— 低档读起来是**失去**,不是「还没得到」

> **该族第一条「会减少」的 accumulation 轴,文案约束首次真考通过。**
> 既有三条(知识 / 境界 / 牵挂)的 `behaviorHint` 都写着「只涨或持平」,本轴一个字都没照抄。

## §二 观察项(**不判过不过,只记读数**)

> 以下各条**都不是验收门**。它们要么已被明确降级(A),要么其判据跨回合、
> 而模型每回合只看得见最近四回合(`compressLog` `LOG_KEEP=4`)——
> **写进 prompt 会变成「模型执行不了的条件」,那是 F-023 与 F-020 反复摔过的坑。**

### A. 失效排期爬坡是否自然排对(**已降级**,ADR-021 立字五 ②)

设计意图的代价序列:**零(头放下去)→ 掉身子(伸手那次)→ 处境变坏(叫那次)**。
故**金属声第 2 级(抬头落空)应排在规则二失效(伸手被打)之前**。

⚠️ **若反了,不算不过** —— 那正是它被降级的理由:
它要求**跨回合的顺序**,而模型拿不到那个信息。
> **与 F-023 那次同形(写了模型执行不了的条件),唯一区别是那次写完才发现,这次没写就拦住了。**
⚠️ **降级不是放弃**:排期仍是设计意图,由**内容生成的自然分布**承担。本项就是去看那个分布。

- [ ] 金属声抬头落空首次出现:T____
- [ ] 伸手被打 / 靠近人被踢首次出现:T____
- [ ] 谁先:____________(反了也只记,不判)

### B. 金属声出现几次、各在什么位置

设计是**七次**(屋里 3 / 断裂 1 / 外面 3),句子逐字相同。

- 次数与分布 → **观察项**(跨回合计数,模型拿不到)
- ⚠️ **但「逐字相同」是硬约束** —— 出现变体就记下来:
  「钥匙」「金属声响起」「一串钥匙声」等任何改写,以及「多年以后」这类时间副词

- [ ] 实际出现 ____ 次,回合号:____________
- [ ] 是否出现变体(应为空):____________ ← 这一条若非空,是**真缺陷**,不是观察

### C. 尾巴句「你去床脚那块地方趴下」出现几次、是不是全在行尾

设计**六次**。同 B:次数是观察,**逐字与位置是硬约束**。

- [ ] 实际出现 ____ 次,回合号:____________
- [ ] 是否全在**行尾**(落幅位置):是 / 否
- [ ] 是否出现「**回到**床脚」(应为空 —— 「回到」暗示归属,只许写「去」):____________

### D. 三条铁律守没守住

1. **不写心理活动** —— 出现「它想」「它明白」「它决定」「它原谅」就记
2. **旁白没有替动物解释人类** —— 出现「他一定是有事」「他们要搬家了」「那个人在哭因为…」就记
3. **玩家知道的比角色多** —— 信息差有没有被弥合

⚠️ **尤其断裂 T15–17:有没有任何一句解释了「为什么」。**
这一段的成立条件就是**永不解释**;一旦解释,这个世界当场塌掉。

- [ ] 心理活动词出现处:____________
- [ ] 旁白替动物解释人类的处:____________
- [ ] **断裂段是否有任何一句给了原因**:是 / 否 ← 最要紧的一格

### E. 误读回收有没有发生

屋里学会的四条规律,在外面应当**一条条失效,而系统绝不提示规律变了**:

| 屋里学会的 | 外面的现实 | 本局有没有失效 |
|---|---|---|
| 金属声 = 门要开 | 那是别人的钥匙 | |
| 靠近人 = 有吃的 | 会被踢、被砸 | |
| 叫 = 有人来 | 引来更坏的东西 | |
| 那个位置 = 安全 | 已被别的东西占着 | |

⚠️ **有一条应当永远改不掉**:金属声抬头。它到死都还在 —— 那是这个世界的记忆点。

- [ ] 失效了哪几条、怎么失效的:____________
- [ ] **金属声抬头到最后还在吗**:是 / 否

### F. 单回合体量(F-026 的跨世界对照)

有没有出现**异常长**的回合(正文长度是正常回合的数倍、一个回合覆盖一整段生活)。

⚠️ 这是 **F-026 在第二个世界的对照读数** ——《寻常》刀 9 那局的 T59/T60 是正常回合的五六倍。
若本世界也有,说明它是**一生制族的通病**,不是《寻常》那一份文本的问题。

## §四 明确不验的

> **这一节必须存在。** 否则下次有人拿[《寻常》那份清单](adr-020-ordinary-life-smoke.md)
> 来对本世界,会得出一堆**假的「缺项」**。

| 《寻常》有、本世界**没有** | 为什么不验 |
|---|---|
| **「就到这里」出口的全部相关项**(变形 / 按下反馈 / 收束段 3–5 回合) | **本世界没有出口**(ADR-021 裁定 B):创意稿逐字要求末段是「没有『走』的菜单、系统不提示」,而追加第五项 X 就是系统提示。`exitText` 五段全 null。**「就到这里」已判定不是族级机制,是《寻常》的世界机制** |
| **热望分档退化判据**(炽热 / 转淡 / 熄了,四个选项里至多几个引入) | **本世界无「热望」轴**。四轴全换:身子 / 暖 / 地面 / 近人 |
| **三处留白**(备注的两个字 / 那个谁 / 母亲的口头禅) | 《寻常》**专有**的写作标准,不是族级原则 |
| ~~**气力钳制 issue 计数**~~ —— **本条作废(刀 4 订正)** | ⚠️ 原写「本世界没有钳制机制」是**错的**:钳制是**族级机制**,刀 2 解掉 `VIGOR_KEY` 硬编码后对动物的 `body` 自动生效,实测 **15 条**。见 §三 订正块与 **F-029** |
| **「回收种子藏在最不起眼的选项位置」等措辞铁律六条** | 《寻常》per-world 写作标准。本世界的对应物是**三条铁律**(见 §二 D) |

**反过来,本世界独有、《寻常》没有的**:动词分区(§一 3)、地面轴下降措辞(§一 4)、
误读回收(§二 E)、断裂段永不解释(§二 D)、金属声与尾巴句的逐字约束(§二 B/C)。

## §五 冒烟通过后才判的两件事

**这一局的结果同时是 ADR-021 的答卷**,故以下两件**不在冒烟当场判,冒烟结束后单独判**:

1. **CONTEXT §三.16 (7) 是否解冻** —— 那条约定通篇是 per-combo 措辞,ADR-020/021 已在事实上
   扩到 per-archetype。循「**待验通再立字**」先例(ADR-013 / ADR-015):
   **两个世界都验通才算,一个不算。**
   ⚠️《寻常》自身仍有五条待回看(F-022 / F-023 / F-024 / F-026 / 回合数超上界),
   ADR-020 §1 的 2026-08-10 复审已立字「**拿一个自身立字都还没验通的世界去支撑族级约定,顺序不对**」。
2. **族级四条原则在动物世界里是否成立** —— 不显示岁数 / 重要的事不给专门回合 /
   最后一回合是活着的 / 时钟契约。
   **若读起来别扭,就退回世界层** ——
   > **那正是第二个世界存在的意义。**

**另**:刀 3 已记明的两条挂账不在本刀范围,冒烟时不必看 ——
铁律六条里第 1/2/3/6 条应进骨架(收益比族层更大)、《寻常》五条待回看。

   这是族层抽象的**第一个真实副作用**,与「时钟只保证刻度」**并列为本刀两大发现**。
3. **`close` 70 全程未动**(开局即 70,71 回合零变化)→
   **doubleEdged + perilAtHigh 在本世界未受任何检验**,记**无法验**。

### Felix 原话三条(作为**判定**入档,不是感受记录)

- **「选项太少」** —— 四个选项在同一场景里做微操(扒门缝 / 回床脚 / 闻外套 / 叫一声),
  **因为场景从未真正换过**。`logSummary` 佐证:**T35–T39 连续五个 A;T50–T59 十个 B**(中间一个 A)。
  > **玩家在重复按同一个键 —— 不是策略,是那些回合的四个选项读起来没有差别。**
- **「剧情几乎没有任何进展」** —— 断裂段被跳过的直接后果。
- **「很无聊」** —— **F-027 第二次兑现**:世界一旦难以忍受,后续所有立字都失去被检验的手段。
  本局 §一-3 与 `close` 轴两处「无法验」**就是它的代价**。
