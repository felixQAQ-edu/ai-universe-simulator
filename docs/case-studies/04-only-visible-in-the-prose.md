## 现象

ADR-028 刀 3 的两条本地真模型短局(R1 / R3a)验收**通过** —— 手册 §六 记的是「**通过**:每回合征兆与反馈事实写进正文……」,
且「ADR-028『重新审视的触发条件』一条都没有触发」。同一次运行,校勘逐回合读正文,另记了四条:

- **F-031**:世界生成的开场叙事(第 0 回合)已经写出纸箱与搬家动作,而纸箱局面的征兆按设计从第 11 回合才开始。
  原文摘句:「屋子里多了几个方方的箱子……把东西放进箱子,搬出去」。
- **F-032**:回合指令第(6)条要求逐字不变的句子,模型在两局里都改写或改换了它。原文摘句:
  「你抬起头。门没有动。你等了一会儿,把头放下去。」/「是别的门——不,这次连别的门也没有响」/「你退到床脚那块地方趴下」。
- **F-033**:正文以第二人称「你」叙述,但夹入第三人称「它」。原文摘句:「孩子叫了它的名字」「它沿着墙根走」「没有一层是它要的」。
- **F-034**:R3a 两处 ——「T16 提前写到天暗(按时钟段,那是 T17 的征兆「天黑了」)」,「T18 出现选项「试着钻回屋里」」。

FINDINGS 给 F-032 与 F-033 的标注都是「**两局都出现,每局都会复现**」。

## 它为什么没被现有守护抓住

**守护守的是 prompt,而这四条的症状都在正文里。**

那一版代码合入前 CI(run 126,`d4b0ae7`)三个 job 全绿,server 595 条 0 失败 0 跳过;
prompt 对拍是「其余四世界 + 两融合 + 《寻常》的 world-gen 与回合 prompt 46 份与 `2476e61` 逐字节一致,
《动物人生》8 份作正对照全部不同;旧局金样本(`583abc9`)仍逐字节一致」(ROADMAP 刀 2 记录)。
这些都在证明「给模型的东西是我们写的那一份」;**模型写回来的东西,没有一条断言在看。**

这条边界后来被逐字写进了 ADR-029 §6(Felix 原文):

> 这张表能确定性地控制 prompt 提供哪些句子，不能保证流式正文一定遵守

同一节把「守不住」列成了清单,第一条就是「流式正文是否遵守(禁用回合实际有没有写出这组句子或其改写)」。

⚠️ **四条的来源并不都在正文侧,如实分开记:**

- F-033 的来源(疑似)**就在 prompt 里** ——「`BoxSceneTables` 里的反馈事实与记忆事实一律用「它」写,模型照搬进正文」。
  prompt 里一直有这些「它」,只是当时没有任何断言看人称;
- F-031 出在 world-gen 的开场叙事,而 ADR-028 写明「world-gen 产出的背景 / 结局池与局面结果之间的一致性**不在本 ADR 处理**(见已知代价 5)」;
- F-032 的规则「早于 ADR-028 就有,不是纸箱局面引入的」。

## ⚠️ 它本可以怎样溜过去

**其一,验收本身是通过的。** 局面结算、时钟、处境、槽位这些引擎侧事实,手册 §六 逐条记为通过;
ADR-028 的重新审视触发条件一条都没触发。只看验收结论,这一轮是干净的。

**其二,机制在没有正文时照样「对」。** 手册 §六 的作废记录:一次 R1 尝试「因本地 key 设置错误每回合都降级、没有正文,
但局面照样从 T11 推进到 T17 并结算为 R1」。**局面层在一个字都没写出来的时候也能走完** ——
只看局面状态,看不出正文写成了什么样。

**其三,开场叙事不进存档。** 手册 §九 9.1:「轨迹里没有开场叙事(开场叙事不进存档),这一屏只能靠截图。」
F-031 发生在第 0 回合,事后能复查的唯一材料是有人当场截下的那一屏。

## 是什么抓住了它

**人工逐回合读正文。** 手册 §六 的记法是「Felix 本地真模型跑两条短局,校勘逐回合判读」;
四个发现「记在 `bakeoff/FINDINGS.md`」,每条带回合号与原文摘句。

不是测试、不是对拍、不是日志。

## 修法

三处修复,都做在 prompt 侧:

- **F-033 → ADR-028 §已决 K**:「定稿原文和落盘内容保持「它」，只在渲染进回合 prompt 时转换为「你」，再加人称硬约束。」
  合并 `37dafe4..6e9b8d8`(2026-10-03),部署 `f7d73ad`(2026-10-03)。
- **F-032 → ADR-029**:金属声句组与床脚句按回合排窗,每回合注入允许或禁用指令。
  合并 `b066016`(2026-10-03),部署 `7815960`(2026-10-03)。
- **F-031 / F-034 → ADR-028 §已决 L**:开场与 T1–10 加纸箱时间锚点;被留下余波 B1–B3「改成只注入当前一拍」;
  离开回合「使用 `OUTSIDE` 片段」、下一组选项「固定使用已定稿的“刚出门”三条模板」。
  合并 `7815960..595b930`(2026-10-04),部署 `8c392c6`(2026-10-04)。

⚠️ **为什么做在 prompt 侧、而不是事后改写正文 —— ADR-028 与 ADR-029 都没有记录这一候选。** 本文不补。

修完之后,各条在 FINDINGS 里的状态一律写作「**真机效果未验**」,持续到 2026-10-09。
手册 §七 / §八 在修复同期就把核读项写好了,两节开头都是同一个意思 ——
§八:「同样只决定 prompt 给什么,不保证正文遵守。下次短局逐回合核读」。

## 怎么验证

2026-10-09,线上 `681721a`,Felix 新开两局(R1 17 回合、R3a 18 回合)。两处和 10-03 那一轮不同:

- **不用夹具,从第 0 回合玩起** —— 手册 §九:「T1–10 与开场要看,夹具从第 10 回合起跑看不到」。
  10-03 那一轮的夹具从第 10 回合起跑,F-031 要验的那几回合在它覆盖范围之外。
- **报告由轨迹核读工具生成,先核对重渲染** —— `TraceRecheckTool` 用回合前状态重渲染 prompt,与记录的 `promptSha256` 比对;
  手册 §9.3:「报告顶部若出现「⚠️⚠️ 重渲染不一致,窗口判读不可信」,说明本地代码与线上渲染 prompt 的代码不同」。
  两份报告都是「prompt 重渲染核对:全部一致」。工具只给线索 ——「结论由人工逐句判读;工具不判定「改写算不算违规」「它指的是谁」」。

结果(手册 §十 / FINDINGS):

- **F-031 线上真机验证通过**:「两局开场与 T1–10 都没有纸箱 / 搬运。」
- **F-033 线上真机验证通过**:「两局共 35 回合,主角零次被称作「它」;R1 的 11 处、R3a 的 2 处「它」都指物。」
- **F-034 线上真机验证通过**:「R3a T15 光落在地板上、T16 光上墙未写天黑、T17「天黑了。」,同一天;T18 选项为「刚出门」三条,正文在楼道。」
- **F-032**:「**允许窗口生效**(R1 T9 两句逐字、R1 A2 整组落空句出现);**禁用窗口仍泄漏**,见 F-037。」

工具自己也误报了一处,记在判读里:「R1 T14「不是以前那种金属声」是 A1 规定的征兆,工具标为疑似改写属误报」。

## 尾声:F-037

这次验证同时把 ADR-029 §6 那条边界**实测了一遍**。F-037 记了三类泄漏(回合号与原文见 FINDINGS):

- **(a) 钥匙**:「R3a 的 world-gen 自写的规则 1 与开场含「钥匙串」;该规则每回合随规则进 prompt,与「正文不许出现钥匙」并存。」
- **(b) 落空句组的改写套语**:「R1 T3 / T5 / T7「有金属碰金属,都不是这一扇」」等。
- **(c) 床脚**:「R3a T12、T13(选「躲进床底」之后)写到「床脚」,T13 近乎原句」。

F-037 的机制事实一句:「ADR-029 只控制每回合注入的**允许原句与禁令**;它**不覆盖 world-gen 产出的规则 / 开场**……也**不识别改写**。」
(a) 这一类,ADR-029 §6 在「能守住」那条里已经写了限定 ——「只覆盖引擎注入部分,模型自己产出、落盘后回喂的 `rules` / `hiddenLogic` 不在其内」。

**F-037 的状态是「只记事实,不下结论」**,未决。本文不写修法。

## 留下了什么判据

只记有锚点的:

- **prompt 侧的修复,收口靠读正文。** ADR-029 §6 写明窗口机制「不能保证流式正文一定遵守」;
  手册 §七 / §八 在修复同期就把「下次短局逐回合核读」写成了核读项;FINDINGS 在读正文之前一律记「真机效果未验」,
  读完才改为「线上真机验证通过」或另立 F-037。
- **读正文要可复现。** 原始轨迹 + 重渲染 sha 核对:重渲染不一致时「窗口判读不可信」,一致才采信;
  报告里的标记「只是线索」,判读由人做,误报也照记(R1 T14)。
- **验证要覆盖缺陷所在的回合。** 10-03 的夹具从第 10 回合起跑,看不到开场与 T1–10;
  10-09 改为从第 0 回合新开局,开场叙事不进存档,于是另截图。
- **「能保证什么」要写进 ADR,并在验证里被逐条对照。** ADR-029 §6 的「守不住」清单,
  在 F-037 里得到实测(F-037:「ADR-029 §6 已写明的保证边界……在此得到实测」)。
