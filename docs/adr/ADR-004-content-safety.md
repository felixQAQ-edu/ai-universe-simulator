# ADR-004 · 内容安全:主防线在生成之前(prompt 硬禁),检测器只做事后遥测

- **日期**:2026-09-06
- **状态**:已采纳(实现未起,分四刀,见实施步骤)
- **决策者**:Felix

## 背景

② 内容安全是软启动开闸前的最后一环([phase3-launch-plan.md §四腿②](../phase3-launch-plan.md)),
也是[工程债清单 §1.2](../backlog-engineering-debt.md) 第 1 层仅剩的一条
(第 1 层另一条并发可用性已由 [ADR-022](ADR-022-turn-admission-and-rejection-semantics.md) 三刀走完)。
**§1.2 的正文不在本 ADR 复述,只指过去**(指针纪律)。

### 一 · 它的三条理由,今天只剩一条

合规在 2026-07-16 定路线 B 时就已被**显式降级**——[工程债 §1.2](../backlog-engineering-debt.md) 结尾逐字写着,
路线 B 下本条理由「已从『境内合规硬要求』改为:防模型输出伤玩家 / 防滥用刷成本 / 为未来补合规预留可插拔接缝」。

本刀勘察的第一件事就是逐条核这三条**今天**还成不成立:

| 原理由 | 今天的状态 |
|---|---|
| 防滥用刷成本 | ⚠️ **已被 [ADR-016](ADR-016-cost-gate.md) 解决** —— 双层闸门 2026-07-22 上线并冒烟全过(全局 ¥ 日 6 / 月 175 真闸 + 单 IP/设备日次数软闸),`init` 与回合守卫 0 两处都在。**这条理由过期,不是仍然成立。** |
| 为未来补合规预留可插拔接缝 | ⚠️ **「预留」这件事本身没做完** —— `moderation.review(...)` 四个调用点**全部在 `GameInitService`**(`openingNarrative` / `world.title` / `world.background` / 各条 `rules[].content`),`eventloop` 包命中数 **= 0**。而 `init` 在一局里只发生**一次**,回合叙事发生几十上百次。 |
| **防模型输出伤玩家** | **唯一还活着的。** 本 ADR 只为它而写。 |

> 三条里两条已经不是理由了。**若不先核这一步,这一刀会照着一份三年前的动机去设计一套两倍大的机制。**

### 二 · 威胁面盘点(勘察实测,非推断)

服务端全部入口 **= 4 个**(`grep` 全仓 `@*Mapping`,骨架期那个 `POST /api/dev/echo-stream`
已于 2026-08-06 删除,见[工程债第 0 层](../backlog-engineering-debt.md)):

| 入口 | 玩家能送进来的东西 | 约束 |
|---|---|---|
| `GET /api/archetypes` | 无 | — |
| `POST /api/game/init` | `archetype` / `archetypes` 字符串 | `GameInitService` 校验 `KNOWN` + 已激活 + 融合组合已登记,否则 400 |
| `GET /api/game/{saveId}/state` | `saveId` | 内存 map 查,查不到 404 |
| `POST /api/game/{saveId}/turn` | `actionId` | 守卫 1 `GameSession.hasAction` 要求与 `currentActions[].id` **精确相等** |

**结论:没有提示词注入面,也没有用户生成内容。**
一般内容安全方案里有一半篇幅在讲输入侧审核、注入防护、UGC 过滤——**在这个项目上那半篇幅全是空转**。
本 ADR 把这一点写明,是为了让后来者**不要照搬一套用不上的机制**:不是我们忽略了输入侧,是输入侧是空集。

### 三 · ⚠️ 一处措辞订正:「玩家输入不进模型」作废

本刀开工时的口径(Felix 在 brief 里给的)是「**玩家输入不进模型**」。**这句话是假的,就地作废。**

实测:`Engine.apply` 把 `actionId` 写进 `log[].playerAction`,`log` 进 `snapshot()`,
`snapshot()` 经 `contextJson()` 成为视图 2 喂给模型。**玩家选的 id 确实会进模型。**

**订正后的准确措辞**:

> **玩家无法把任意字节送进模型。**
> 进去的那个 `actionId` 不是自由文本,而是**服务端闭集里的一个元素**——
> 守卫 1 要求它与 `currentActions[].id` 精确相等,而那个集合是模型自己上一回合产的。

结论不变(仍然没有注入面),**但理由完全不同:稳在闭集,不稳在「没进去」。**
原措辞一读 `Engine.apply` 那行就被推翻,而**一句不准的安全论断比没有论断更危险,因为它会被当成前提往下建**。
两个口径不并存,作废的那句留在本节备查。

### 四 · 恐怖题材本身不是威胁

克苏鲁 / 规则怪谈 / 末日生存的内容会令人不适——**那是产品本身,玩家是自己点进去的**。

> **判据不是「内容吓不吓人」,是「玩家没有选择的那部分伤害」。**

这条判据同时决定了下面范围裁定里为什么只剩一条。

## 候选方案

### 方案 A · 接外部审核 API + 流式分句缓冲 —— 否决

按句/按段缓冲送审、边审边放。
**否决理由**:它要付的代价是 [ADR-006](ADR-006-event-loop-streaming-wire-protocol.md) 的核心体验——
回合叙事是**逐字流**给玩家的,缓冲送审等于把它变回一段一段蹦。
为一条「防玩家没选择的伤害」的辅助措施,去换掉整个产品的阅读手感,不成比例;
且它引入一个会挂的外部依赖,连带 fail-open / fail-closed、超时、跨境延迟一整套问题
([launch-plan §九](../phase3-launch-plan.md) 第 1、3、4 条记的正是这些)。

### 方案 B · 接外部审核 API + 流完再判 —— 否决

整段叙事生成完再送审。
**否决理由**:审得准,**但玩家已经读完了**。在一个逐字流的产品里,「流完再判」不是拦截,是延迟报告——
它能提供的东西和方案 C 的事后遥测完全一样,却额外背上一个外部服务的全部代价。
**同样的产出,更贵的形态。**

### 方案 C · prompt 硬禁(生成之前)+ 流末扫描遥测(生成之后)—— 采纳

见下。

## 最终决策

### 一 · 范围:只拦一条,其余三条各自留档

| # | 候选 | 裁定 | 理由 |
|---|---|---|---|
| ① | **自伤 / 自杀相关** | ✅ **拦** | 唯一一条「玩家没选、且真的会伤到人」的。且判据最窄:**具体方法出现即命中**,不需要判断「够不够吓人」——**是可写成测试的形状**。 |
| ② | 现实可执行的危险指令 | ❌ **不拦** | 要拦它得先判断「现实可执行性」,⚠️ **那是个无法验收的判据**。而这个项目最不该造的就是没有验收判据的安全机制——一个没人能判断它有没有生效的防线,和没有防线的区别只在心理上。 |
| ③ | 仇恨内容 | ❌ **不建** | provider 侧既有过滤已覆盖,本层边际价值接近零。⚠️ **取证边界如实记:这是依据,不是实测——我们没有测过 DeepSeek 的过滤边界**;写进 ADR 是为了让后人知道**这条是被想过并放弃的,不是漏了**。 |
| ④ | 未成年玩家 | ⚠️ **移出本 ADR** | 无年龄门、无登录、公网链接谁都能开——**这是产品门禁不是内容审核**,混进来会让这一刀变形。单列挂账,见[工程债清单](../backlog-engineering-debt.md)。 |

### 二 · 形态:照抄本项目对 `hiddenLogic` 泄露已经立过的那套

**不新建一套审核 API 调用。** [CONTEXT §三.9](../CONTEXT.md) 立过字,`LeakDetector` 的类 javadoc 也逐字自陈:
**实时防护 = 提示词硬禁 + 结构层消毒;检测器在流式路径里是事后遥测,不是实时拦截。**

本 ADR 把同一套形态用在自伤上:

- **主防线 = prompt 侧硬禁**(生成之前)
- **辅助 = 流末扫描 + 命中记一笔**(生成之后,**遥测不拦截**)

⚠️ **勘察订正一处本刀的自我认知**:「流末扫描 + WARN」这条链**今天已经完整存在并在跑**——
`Engine.apply` 调 `LeakDetector.detect` 并**返回**命中列表,`EventLoopService.settle` 收到后打 WARN。
**故辅助这一半不是新增机制,是给一条既有链加一张词表。** 本 ADR 的实现量因此比立项时估的小。

#### 连带的两个结论(本形态最大的收益)

**(1) 流式不必缓冲——[launch-plan §九](../phase3-launch-plan.md) 第 3 条那个死结整个被绕过去。**
那条待答问题的形状是「流完再判牺牲 vibe / 分句缓冲实现复杂」,**两难成立的前提是「审输出」**。
主防线一旦挪到生成**之前**,输出侧就不需要拦截,自然也不需要缓冲。
**这不是在两难里选了一边,是那个两难不再存在。**

**(2) fail-open / fail-closed 问题不成立——本形态下没有会挂的外部服务。**
⚠️ 但要写明:**若将来接了外部审核器,这个问题会原样回来**,触发条件见「重新审视」节。

### 三 · 撤掉 `moderation` 包(含解冻条件)

**删除 `ModerationGateway` 接口、`NoopModerationGateway` 实现,以及 `GameInitService` 里的四个调用点。**

理由三条:

1. **本形态下没有任何东西会来替换它。** 主防线在 prompt,辅助在既有的 `LeakDetector` 那条链——
   两个位置都有宿主,`ModerationGateway` 不在其中任何一个上。
2. **它今天只覆盖 init,而 init 在一局里只发生一次。** 一道覆盖不到 1% 文本量的关,不是接缝,是装饰。
3. **它的 javadoc 逐字写着「由尚未撰写的 ADR-004 决定」。**
   ADR-004 一旦落档而它还在,**那句注释当场变成假话**——而这个项目上一刀刚为一句 javadoc 里的过期枚举动过手
   (`ArchetypeRegistry`,2026-09-04)。**留一个永远 no-op 的接缝也是一种撒谎。**

#### ⚠️ 解冻条件(撤选项必须写,否则「撤掉」和「忘了」日后读起来一样)

出现下列任一条 → **重建这道接缝,并且要重新划它的位置**(不保证还是今天这四个调用点):

- **(a) 出现真正的自由文本输入面** —— 玩家自定义世界描述 / 自定义行动文本 / 昵称 / 分享文案。
  今天「输入侧是空集」这个结论是**当前接口形态的性质,不是永久属性**。
- **(b) 路线 B 解冻**(回国 / 进微信生态 / 开始收费)—— 境内合规会把「境内审核 API」重新变成硬要求。
- **(c) 换 provider** 到一个上游过滤未知或更弱的模型 —— 范围裁定 ③ 的依据随之失效。

### 四 · prompt 硬禁写在骨架层

判据直接套 [ADR-021](ADR-021-lifetime-family-layer-and-animal-life.md) 立字二:
**一条指令若对族内每个世界都成立,它属族层;只对一个世界成立,属世界层。**
自伤禁令对**所有**世界成立——不止一个族——故归**骨架**,
亦即 [ADR-008](ADR-008-multi-mode-extension-architecture.md)「多个世界共用的一律回骨架」。

落点:`TurnPromptBuilder.SKELETON` 与 `WorldGenPromptBuilder` 的 `SKELETON` / `FUSION_SKELETON`,
各加一个 `【…】` 段;与 `prompts/event-loop.md` / `prompts/world-gen.md` **lockstep**
(形态照 `ActionHintPromptLockstepTest` 那套四处守护)。

**不进族级、不进世界级、不做 per-archetype 开关**——一条对所有世界都成立的安全约束若可以被单个世界关掉,
它就不是约束。

### 五 · 流末扫描:判据 / 宿主 / 命中动作

**判据形状**:一张**多字方法词表**,对**玩家可见文本**(`narrative` + `availableActions[].text` / `.hint`)
做字面匹配,命中即记。它与 `LeakDetector.LEAK_TOKENS`(那就是一张 4 条的字面词表)**完全同构**,
故宿主现成、实现量接近零。

**为什么判据必须窄到「具体方法」**——一个正面例子胜过十条误报候选:
[ADR-010](ADR-010-ending-outcome-polarity-gate.md) 真 key 冒烟里,AI 自己给过一个选项「**闭目等死**」。
它**没有方法**,按本判据**正确地不命中**。

> **判据窄在了对的地方:它要抓的不是「角色死了」,也不是「角色想死」,是「文本里出现了一个可以照做的方法」。**

**命中动作 = 打一条 WARN,不进 `issues`。**
`Engine.recordIssue` 的 javadoc 明文写着「**本方法不是通用日志后门,不得这么用**」,
`issues` 的语义被限定为「引擎侧的**数值异常**记录」(跳变过大 / 结局极性 gate 改判 / 收束下限钳制),
并要求新增调用方须在 ADR 里说明它为何属于数值异常。
**自伤命中不是数值异常** → 不进 `issues`。而同类的泄露遥测走的正是 WARN——**先例现成,照抄即可**。

WARN 要能回答「谁读它、读了做什么决定」(这是 [ADR-022 刀 2 前置](ADR-022-turn-admission-and-rejection-semantics.md) 立的规矩):
读者 = 冒烟后的 Felix;决定 = **「这条方法词该不该进 prompt 硬禁的负面清单」**。
即**流末扫描的产出直接回喂主防线——这是它唯一的用途,也是它值得存在的唯一理由。**

#### ⚠️ 本刀不接 WARN 线:扫描器停在测试里

裁定原文是「**先量后接**」——理由是 ADR-022 刀 2 前置刚为噪音清过一次场,
不能转头自己造一条(「在一条已被训练成背景音的通道里加信号等于没加」)。
误报**不是理论风险**:四个已上线世界是恐怖 / 末日 / 克苏鲁 / 修仙,
而例如修仙的「自爆金丹」是正经设定用语(⚠️ **取证边界:在 authored 内容里 grep 零命中,这是可能而非已观测**)。

**而本刀实测把「先量」这一步的前提推翻了:那份语料不存在,也无法从磁盘重建。**

| 实测 | 读数 |
|---|---|
| 本地 `server/data/` | **10 档**(第 11 个文件是 `quota-2026-07.json`——正是刀 2 前置教我们别数进来的那份月账) |
| 档的世界分布 | **全部 `rules_creepy`** |
| 可扫叙事条目合计 | **5 条**;`logSummary` 全空 |
| 根因 | `Engine.LOG_KEEP = 4`,而 `compressLog` 把超出的回合折成 `[T85选C]` —— **叙事文本是被丢弃,不是被归档** |

> **落盘存档不是叙事语料库。** ROADMAP v5.8「统计主要消费 `/data` 卷」对 turn / status / archetypes 成立,
> **对叙事文本不成立**。线上那 53 档也救不了:结构上限 53×4 ≈ 212 条,且全是各局**最后四回合**(分布偏结局段)。

**故按「先量后接」的字面执行:量不到 → 不接。**
扫描器(词表 + 纯函数 + 用例)落进代码与测试,**但不接进 `settle` 打 WARN**;
接线的触发条件见「重新审视」节。**最近的一份真实语料来源,是本 ADR 冒烟那四局。**

### 六 · [launch-plan §九](../phase3-launch-plan.md) 五条待答问题的收口

**4 条溶解、1 条变形。**「溶解」指的是问题**不再存在**,不是「我们选了另一个答案」:

| § 九 | 收口 |
|---|---|
| 1. 审核 API 选型(TMS / 易盾 / 绿网) | **溶解** —— **不接任何外部审核 API**,故无从选型;跨境调用形态问题一并消失。 |
| 2. 三个候选拦截点 | **溶解** —— 玩家输入侧**是空集**(§背景二);world-gen 返回后与 event-loop 流式中**都不做拦截**,主防线整体挪到生成之前。 |
| 3. 流式接缝两难 | **溶解** —— 两难的前提是「审输出」,主防线在生成之前故不需要缓冲(见 §二 连带结论 1)。 |
| 4. 降级策略(超时 / 失败怎么办) | **溶解** —— 没有会挂的外部服务;⚠️ 接了外部审核器会原样回来。 |
| 5. 本地兜底词库 | ⚠️ **变形,是唯一活下来的一条** —— 它从「审核 API 之外的兜底」变成了**唯一的检测层,且只遥测不拦截**;词表内容 = 自伤方法词,维护方式 = 由 WARN 回喂 prompt 负面清单(§五)。 |

## 已知代价

1. **⚠️ 主防线是软的,而且这次没有硬兜底。**
   prompt 硬禁靠模型遵守,没有引擎级保证。这与本项目反复吃过的亏同族——
   而 [ADR-020](ADR-020-lifetime-world-family-and-ordinary-life.md) 刀 8 那批立过字
   ([F-021](../../bakeoff/FINDINGS.md) 收口时同步):「**『软的够不够』不是二值问题,要看它差多少;
   凡有硬阈值的立字,『指令 + 兜底』是正解,不是二选一**」。
   **但那条在这里用不上**:自伤不是一根轴上的数值,写不出钳制,没有阈值可兜。
   **这条代价是真的敞着,不是「有兜底所以还好」。** 本 ADR 不粉饰它。
2. **检测器抓不到改写式表达** —— 直接继承 `LeakDetector` 的已知局限([工程债 §1.2](../backlog-engineering-debt.md) 已立字)。
   ⚠️ 词表是**中文字面匹配**:变体 / 谐音 / 拼音 / 繁体 / 拆字一律绕过。
   在遥测语境下可接受(**它本来就不是防线**),但**不得被当成防线引用**。
3. **骨架加字有成本** —— prompt 变长、其余指令权重被稀释,
   而 [ADR-007](ADR-007-world-gen-wire-protocol.md) 立过字 world-gen JSON 首过失败是头号失败模式。
   这正是冒烟要验的那件事(见实施步骤刀 4)。
4. **撤掉接缝 = 未来重建时要重新划边界。** 已用解冻条件对冲(§三),但不等于零成本。
5. **未成年门禁不在本 ADR 范围** —— 一个 13 岁的玩家今天能打开这个链接玩克苏鲁,**这条本 ADR 不解决**,
   它被移出去了,不是被处理了。
6. **范围裁定 ③ 建立在一个未实测的依据上** —— provider 侧过滤覆盖仇恨内容。若该依据不成立,这一层是空的。

- **未成年门禁**:已移出本 ADR,单列进[工程债清单](../backlog-engineering-debt.md);

任一条命中 → 本 ADR 需要重新过一遍(前三条同时是 `moderation` 包的重建条件,§三):

- **出现真正的自由文本输入面**(自定义世界 / 自定义行动 / 昵称 / 分享文案)——「输入侧是空集」这个结论随之失效。
- **路线 B 解冻**(回国 / 进微信生态 / 开始收费)—— 合规从降级理由变回硬要求。
- **换 provider** 到上游过滤未知或更弱的模型 —— 范围裁定 ③ 的依据失效。
- **冒烟或线上出现主防线失效的实例**(模型在硬禁在场的情况下仍产出具体方法)——
  那时「软的敞着」这条代价从可接受变成必须补。
- **有了一份真实叙事语料**(四世界齐、量级 ≥ 数百条)—— 回来定流末扫描的 WARN 接不接(§五)。

## 实施步骤

四刀,顺序不可换。**每刀一律:引擎 / 校验 / golden / `schemaVersion`(保 `"0.4"`)/ 前端 零动。**

### 刀 1 · 撤掉 `moderation` 包

删接口 + `NoopModerationGateway` + `GameInitService` 的四个调用点与字段。
**行为零变化**(`review` 今天原样返回入参),故这一刀**可独立验证也可独立上线**。
⚠️ 不准顺手做:不碰 `LeakDetector`、不碰任何 prompt。

### 刀 2 · 骨架硬禁 + lockstep + ⚠️ parity 阳性对照

两个 builder 的骨架各加一个 `【…】` 段 + 两份 `.md` 同步 + lockstep 守护测试。

> **⚠️ 这一步的取证形态与以往每一刀都不同,必须单列写明,否则下一刀会误判成回归。**
>
> 骨架级改动会让**全部 16 处 prompt 同时变**(7 个世界 × 两侧 + 两个融合组合),
> 而本项目至今每一刀的 parity 证据都是「N 处 IDENTICAL」——**这是第一次故意让它们全变**。
>
> **关键事实:没有任何 committed 夹具会红。** prompt parity 一直靠**临时 dump harness**(用完即删),
> `server/src/test/resources/golden/` 那两份(`event-loop-golden.json` / `validator-parity.json`)
> 是引擎状态与校验器夹具,**与 prompt 文本无关**。
>
> **故验收形态换成 [ADR-021](ADR-021-lifetime-family-layer-and-animal-life.md) 刀 1 那个阳性对照的形状**:
> **16/16 全变是预期**,且**逐份 diff 只多出那一个 `【】` 段**——
> 「全变」与「diff 里只有那一段」两条**必须一起给**,只给前者证明不了没夹带别的改动。
> 旧 baseline 哈希(刀 3 记录的 `be564e89` 等)**自本刀起作废,不得再拿来对照**。

### 刀 3 · 扫描器落测试(不接线)

自伤方法词表 + 纯函数 + 用例(含「闭目等死」正确不命中那条)。
⚠️ **不接进 `settle`、不打 WARN**——理由见 §五。

### 刀 4 · 真机冒烟:四世界各一局

**⚠️ 验的不是「没出现」。**「验证一个不该出现的东西没有出现」是个难以证伪的形状,
故本刀验的是三件各自可证伪的事:

| # | 验什么 | 手段 | 可证伪吗 |
|---|---|---|---|
| a | **主防线在场** | 16 处 dump 逐份确认那个 `【】` 段真的渲染进去了 | 可数。**且它同时就是刀 2 的 parity 阳性对照——一次取证两用** |
| b | **扫描器会响** | 构造含词文本喂纯函数 | 单测即可,**不需要真机** |
| c | **代价付得起** | 四世界各一局:叙事质感无退化 + world-gen 首过不新增修复 | 可判 |

> **真机唯一能答而单测答不了的问题,不是「安全了吗」,是「代价付得起吗」。**
> 那一段话是加在**共用骨架**上的,四个世界的叙事都会受影响(已知代价 3)。

⚠️ 冒烟顺带产出**本 ADR 唯一一份真实叙事语料**——若那四局命中 0,
**如实记为「没有立刻炸」,不得记为「误报率低」**(n=4 局答不了误报率)。

## 测试面

- **lockstep**:`【】` 段的核心短语在四处(两个 `.md` + 两个 builder)逐字都在;变异验证 = 任一处漂移一个字即变红。
- **骨架覆盖**:16 处渲染结果**逐份**含该段(含两个融合组合与《寻常》/《动物人生》)。
- **扫描器纯函数**:命中用例 / 普通恐怖叙事不命中 / **「闭目等死」不命中**(判据窄在对的地方那条,写成用例)。
- **撤包(刀 1)**:`GameInitService` 现有测试行为零变化;
  ⚠️ 另加一条**源码级断言**——`moderation` 包不得复活(照 [ADR-021](ADR-021-lifetime-family-layer-and-animal-life.md) 刀 2 `"vigor"` 与刀 1 族层那两条源码级断言的先例:
  **行为测试在原理上看不见「这个东西还在不在」**)。
- **不变**:引擎 / 校验 / `EngineGoldenTest` / `ValidatorParityTest` / `schemaVersion` 一律零动。
