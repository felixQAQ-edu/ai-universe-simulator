## 1. 背景

### 1.1 F-032:三处改写与高频现象

FINDINGS F-032 原文(「(6)条逐字句」被改写,两局都出现,每局都会复现):

> - R1 T11 / T15 / T16:「你抬起头。门没有动。你等了一会儿,把头放下去。」
> - R3a T16:「是别的门——不,这次连别的门也没有响」
> - R3a T17:「你退到床脚那块地方趴下」
>
> 这条规则早于 ADR-028 就有,不是纸箱局面引入的。

被改写的是新局回合主干第 (6) 条要求逐字不变的那组句子
(`TurnPromptBuilder.java:294-298` 新局 / `:399-403` 旧局,两处文字相同):

> 「楼道里有金属碰金属的声音。」(不许出现「钥匙」,不许出现「多年以后」)
> 「你去床脚那块地方趴下。」(不写「回到」——那暗示归属;只写「去」)
> 「你抬起头。」「是别的门。」「你把头放下去。」「不是。」「你抬了一下头。」

R1 三个回合(T11 / T15 / T16)都出现同一形态,本身就是「频率」问题:第 (6) 条只规定**怎么写**,
从不规定**什么时候写**,模型便在任何一个能挂上门声的回合里重写这一组情节。

### 1.2 ADR-021 当时为什么把频率降级为观察项

[ADR-021 立字五](ADR-021-lifetime-family-layer-and-animal-life.md)(2)(`:320`):

> **(2) 失效排期爬坡:金属声第 2 级(外面早期)必须排在规则二失效之前。**
> 代价序列须是:**零(头放下去) → 掉身子(伸手那次) → 处境变坏(叫那次)**。

同一 ADR 刀 3 的落法(`:591`、`:594`):

> **(2) 失效排期爬坡降级为观察项** —— 它要求跨回合的顺序,而 `LOG_KEEP=4` 给不了。
>
> 金属声「七次」与尾巴句「六次」的**位置分布**同样降级为观察项(「逐字不变」留作硬约束)。

冒烟清单 [`docs/adr-021-animal-life-smoke.md:158-185`](../adr-021-animal-life-smoke.md) 照此只记次数与位置:
「设计是**七次**(屋里 3 / 断裂 1 / 外面 3)」「次数与分布 → **观察项**(跨回合计数,模型拿不到)」
「⚠️ 但「逐字相同」是硬约束」;尾巴句「设计**六次**。同 B:次数是观察,**逐字与位置是硬约束**」。

降级的理由是**模型拿不到跨回合的信息**。本 ADR 不让模型去数 —— 排期由引擎按回合号与局面状态确定性算出,
每回合只告诉模型「这一回合允许或禁用」;这正是 ADR-021 当时缺的那条路。

### 1.3 ADR-028 之后,旧回合号对不上

旧设计的位置是按 ADR-021 刀 3 那张五段时钟写的(旧局仍用,`LifeStageTables.ANIMAL_LIFE_LEGACY`):
屋里 T1–14 / 断裂 T15–17 / 外面·早期 T18–27 / 外面·中期 T28–41 / 末段 T42–。
`LifeStageTables.java:88` 的注释至今写着:

> 三个「不是。」递减级的位置与本表精确吻合:T19 在外面·早期、T34 在外面·中期、T45 在末段。

ADR-028 之后新局不再是这张表:T11–14 换成纸箱局面,T15–17 换成按结算结果分叉的余波
(被带走 = 新屋 A1–A3,被留下 = 空旧屋 B1–B3),T18–41 分四段且**不决定地点**(ADR-028 §已决 A / C)。
「外面·早期」「外面·中期」两段在新局里已不存在;R1 / R2 两条路径**可能一辈子不出门**(NEW_HOME 第一版无离开转换,
§已决 D)。旧位置(屋里 3 / 断裂 1 / 外面 3,「不是。」在 T19 / T34 / T45)因此在新局里没有对应的回合可落。

不为 `NEW_HOME`、`EMPTY_HOME`、`OUTSIDE` 各做一套后续窗口。首次落空由 A2 或 R3 T18 承担；T30、T45 是共用的稀疏回声。若某局已结束、地点不适合或当回合没有相应声音，就跳过，不追赶次数。

「你去床脚那块地方趴下。」也纳入控制，但**单独排窗**，不跟金属声绑定：只在最初旧屋的 T6、T10 允许使用，且当回合行动确实使它走向床脚时才写。其他回合禁用。`EMPTY_HOME` 的“躲回床底”是另一个动作，不能为了回收原句改写成“去床脚”；`NEW_HOME` 和 `OUTSIDE` 也不能凭空出现旧屋床脚。原设计的六次不作为新版指标。

“钥匙”冲突这样收：第（6）条对玩家正文的禁令保留；世界生成说明与 `OUTSIDE` 片段中的「那是别人的钥匙、别人的门」改为「那声音来自别的门，不是它等的那一扇」。给模型的对应关系也不要再把声音明确解释成钥匙，避免这类词经 `rules` 或 `hiddenLogic` 回流到逐回合 prompt。

实施简报必须注明保证范围：测试能证明正确窗口被注入、其他窗口收到禁用指令；流式正文仍可能违约。尤其 ADR-021 的“抬头落空先于伸手被打”，只凭 T18 的 prompt 安排无法证明玩家确实先看到了落空。如果仍把它列为硬保证，就需要另做可验证的正文呈现机制；本刀只能把 T18 的伤害情节禁掉，并将实际先后顺序列入短局人工检查，不能宣称已经确定性守住。

ADR-029 §4 按你这版定稿，做以下三处修改后采纳。
一、两行总引导只留在 ADR 的说明里，不要每回合注入七句原文。
新局的第（6）条改为按窗口提供原句：本回合只注入当前允许的句子；没有允许句子的回合，不在 prompt 中列出这七句。共同指令用：
【逐字句窗口 · 本回合】仅可使用下方列出的原句；未列出的逐字句本回合不使用。使用时必须逐字相同，不改字，不在句后接其他文字。若下方没有原句，本回合不使用逐字句。
然后由判定结果填入本回合可用的原句及对应说明。禁用窗口不要再重复列出被禁用句子的全文。旧局与其他世界仍保留原有 prompt。
这是安排表发挥作用的必要条件；如果原第（6）条仍每回合完整列出七句，仅在末尾追加“本回合禁用”，模型还是每回合都会看到它们。

这组逐字句允许使用，但不要求逐字句一定出现；已定的 A2 征兆仍必须写到。不得因为没有使用逐字句，就省去走廊里的金属声和门没有打开这两个事实。

若本回合使用完整落空句组，声音应来自旧家附近的楼道，旧家的门没有打开；若本回合没有写到合适的声音，就跳过这组句子，不补演。无论是否使用句组，本回合都不得安排“靠近人后被踢、被砸或伸手被打”。
这样 T18 不会一边规定声音发生，一边又说“没有声音就跳过”。
三、T45 避免再次列出禁用句原文。
将“不得补写此前没有写出的「是别的门。」「不是。」”改为：
不得在本回合补演此前跳过的落空级别。
其余窗口措辞、床脚句的独立窗口，以及你对 A1、B1–B3、G1–G10 的处理，我确认。床脚句只在 T6、T10 且行动确实走向床脚时进入“本回合可用原句”，不能在其他回合的禁用指令里反复列出原文。

## 3. 窗口判定:输入、规则与逐回合安排

### 3.1 一个确定性的纯函数,两条独立的窗口序列

判定写成**纯函数**(第二步落在 `BoxSceneTurn` 旁,形状同 `stageOverride`):输入是下列会话事实,输出是两个窗口编号 ——
**金属声句组窗口**与**床脚句窗口**,两条序列互不依赖,同一回合两条都有值。模型不参与判定,也不需要知道别的回合。

| 输入 | 取自 | 用途 |
|---|---|---|
| 回合号 `n` | 正在生成的那一回合 = `engine.turn() + 1`(与骨架末行「请推进第 N 回合」同一个 N) | T4 / T9 / T6 / T10 / T30 / T45 与「R3 的 T18」 |
| 是否旧局 | `BoxSceneState.isLegacy()` / 无局面键 | 旧局:**不注入**(§7) |
| 结算结果 | 本回合编排的 `Plan.newResult()`(结算发生在生成那一刻,故取编排而不是落地前存档;编排为 `null` 时回落存档 `st.result`) | R1 / R2(被带走)与 R3a/b/c(被留下)分路;未结算 = 纸箱或旧屋 |
| 处境 | 本回合编排的 `Plan.newSituation()`(离开那一回合已是 `OUTSIDE`);编排为 `null` 时回落 `st.situation` | **只用于床脚句禁用文字的选择**(`EMPTY_HOME` 一句 / `NEW_HOME`、`OUTSIDE` 一句);金属声序列不读它 |
| 本回合的余波拍 | 本回合编排所用的那一拍(`BoxScene.aftermath(t, result).get(n − settledTurn)` 的拍号) | **按拍判定 A2**,不硬写回合号:R1 在 T15、R2 在 T16 |
| 局是否已结束 | `engine.status()` | 已结束 → 不注入(见下注) |

规则(按顺序取第一条命中的):

**金属声句组**
1. 旧局 / 局已结束 → 不注入。
2. 未结算且 `n ∈ {4, 9}` → **M-旧屋**(允许)。
3. 本回合是纸箱阶段 1–4 的拍(`S1`–`S3`、`S4_HIGH` / `S4_LOW`)→ **M-纸箱**(禁用)。
4. 本回合是余波拍 `A1` → **M-A1**(禁用)。
5. 本回合是余波拍 `A2` → **M-A2**(允许)。
6. 本回合是余波拍 `B1`–`B3` → **M-B**(禁用)。
7. 结果 ∈ {R3a, R3b, R3c} 且 `n = 窗口末回合 + 1`(= 18,由 `BoxSceneTurn.windowEnd` 派生,不写字面量)→ **M-T18**(允许),
   **不看处境**:仍在 `EMPTY_HOME` 与 T17 选了 `LEAVE_HOME`、T18 已是 `OUTSIDE` 两种都命中。
8. `n = 30` → **M-T30**(允许);`n = 45` → **M-T45**(允许)。所有路径共用,不按处境分套。
9. 其余 → **M-其余**(禁用)。

**床脚句**
1. 旧局 / 局已结束 → 不注入。
2. 未结算且 `n ∈ {6, 10}` → **B-允许**。
3. 处境 = `EMPTY_HOME` → **B-禁用·床底**。
4. 处境 ∈ {`NEW_HOME`, `OUTSIDE`} → **B-禁用·新屋屋外**。
5. 其余(旧屋其他回合、纸箱回合)→ **B-禁用**。

注:
- **「局已结束」是防御性输入**:`ENDED` 的局在控制器与守卫 2 就被挡下(ADR-023 / ADR-027),不会走到构造回合 prompt。
  它进输入表是为了让纯函数本身对这个状态有定义,不是因为今天有调用路径会传进来。
- **「处境」对金属声序列是冗余的**:勘察中逐条核过,金属声的每一条规则都能由回合号 + 结果 + 拍号决定
  (「仍在最初的旧屋」= 未结算且 `n ≤ 10`,纸箱从 T11 起)。它只在床脚句禁用文字的选择上起作用。
- **拍号今天不在 `Plan` 里**:`Plan` 只带征兆文字(`omen`),不带拍号。第二步须把拍号作为编排的一部分带出来,
  **不能**用「回合号 − 结算回合 = 1」这类算式在判定函数里重算(那等于把局面层的规则复制一份)。
