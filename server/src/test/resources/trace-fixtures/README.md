# 回合轨迹回归夹具(ADR-031 刀 5a)

本目录下每个 `*.jsonl` 是一份回归夹具,由 `TraceFixtureReplayTest` 逐行做档 1 回放,差异必须为空。

**放进来之前必须满足(ADR-031 已决 W-11,runbook §七「转换为回归夹具」):**

- 只来自 Felix 为夹具**专门开的、本人玩的局**;线上取回的原始 `.trace.jsonl` **一律不进仓库**。
- 必须由 `TraceFixtureTool` 转换(白名单字段 + saveId 替换 + 档 1 自检 + 敏感形态扫描)。
- 转换报告里的字段清单、每行 actionId、扫描结果**经人工核对**后才提交;无法明确划出安全字段,则不公开提交。

目录为空时测试照样通过(打一行提示)。本文件不是夹具,测试只读 `*.jsonl`。
